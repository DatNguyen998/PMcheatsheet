# Archived: static HTML/CSS/JS site

This was the working "Modern Knowledge Dashboard" cheat sheet — a
self-contained `index.html` + `assets/` with no build step, all PM content
hardcoded in `assets/js/data.js`.

It was retired (not deleted) when the project moved to a database-backed
architecture: content now lives in Supabase and the UI is a Next.js app (see
the repo root). This folder is kept for reference and rollback; it still runs
fine on its own — just open `index.html` in a browser, or serve the folder
with any static file server.
